# 📊 Projeto - Telecom X: Análise de Evasão de Clientes

Este projeto faz parte do desafio **Churn de Clientes da Telecom X**.  
O objetivo é entender os fatores que levam os clientes a cancelarem seus serviços e gerar insights que auxiliem a empresa a reduzir a evasão.

---

## 🚀 Tecnologias Utilizadas
- **Python 3**
- **Pandas** → manipulação e limpeza de dados
- **Matplotlib** → criação de gráficos
- **Requests** → extração de dados via API

---

## 📊 Passos da Análise
1. **Extração:** os dados foram importados do JSON hospedado no GitHub.  
2. **Transformação:** colunas renomeadas, dados convertidos para numéricos, criação de faixas de tempo de contrato.  
3. **Análise:** geração de estatísticas descritivas e gráficos exploratórios.  
4. **Conclusão:** relatório com recomendações estratégicas para reduzir o churn.

---

## 📈 Principais Insights
- Clientes com **contratos mensais** cancelam mais.  
- Pagamento por **boleto eletrônico** tem maior taxa de churn.  
- Clientes com **fibra óptica** apresentam churn maior que DSL.  
- Clientes com **até 1 ano de contrato** cancelam mais frequentemente.  

---

## ✅ Conclusão Final
Para reduzir o churn, a **Telecom X** deve:  
- Incentivar migração de clientes para **contratos anuais** com descontos.  
- Promover **métodos de pagamento mais estáveis** como débito automático.  
- Melhorar a **qualidade e suporte do serviço de fibra óptica**.  
- Criar um **programa de fidelização para novos clientes** nos primeiros 12 meses.  

Essas ações podem reduzir significativamente a evasão e aumentar a retenção de clientes.
